# Integration Boutique Website

Professional MuleSoft integration consulting website with AI Foundation capabilities.

## 🚀 Quick Deploy to Netlify

### Option 1: Drag & Drop (Easiest)
1. Go to https://app.netlify.com/drop
2. Drag the entire `integrationboutique` folder
3. Done\! Your site is live

### Option 2: Git Deploy (Recommended)
1. Push to GitHub/GitLab/Bitbucket
2. Connect to Netlify
3. Deploy automatically on every push

See **`NETLIFY_SETUP.md`** for detailed instructions.

## 📧 Form Submissions - Company Name in Subject\!

### Email Subject Format
```
🎯 New Consultation: [Company Name] - [Service]
```

**Examples:**
- 🎯 New Consultation: Acme Corp - AI Foundation Strategy
- 🎯 New Consultation: TechStart Inc - Platform Migration

### Setup (2 minutes after deployment)

1. Go to Netlify Dashboard → **Forms**
2. Click **"consultation"** form
3. Click **"Form notifications"**
4. Add **Email notification**
5. Set recipient: `connect@integrationboutique.com`
6. Save

✅ Done\! Company name automatically appears in every email subject.
